# Voorraadkast PWA

Dit pakket is de PWA-versie van Voorraadkast v9.

Bestanden:
- `index.html` — de app
- `manifest.webmanifest` — PWA-configuratie
- `sw.js` — eenvoudige offline cache voor de eigen app-bestanden
- `icons/` — app-iconen

Publiceer de inhoud van deze map op GitHub Pages. Daarna kan je op iPhone in Safari via **Delen → Zet op beginscherm → Open als webapp** installeren.
